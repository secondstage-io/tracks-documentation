# DV360 Floodlight Conversions

<p class="docs-audience">For: Ad ops / programmatic lead</p>

!!! note

    Complete the [DV360 access integration](../../platform/mediachannels/dv360.md) first.

TRACKS sends installs to Display & Video 360 as **offline Floodlight conversions** through Google's **Data Manager API**, matched to the DV360 click ID (`dclid`). DV360 postbacks are only available this way: no web pixel or SDK is involved.

## What we need

<ol class="setup-steps" markdown="1">

<li markdown="block">

### Floodlight configuration ID

Send us the ID of the Floodlight configuration your advertiser uses.

</li>

<li markdown="block">

### A dedicated offline Floodlight activity

Create one Floodlight activity per event (for example "TRACKS Install"). Keep it separate from your website activities, so installs don't mix into your web Lead or PageView counts.

</li>

<li markdown="block">

### Auto-tagging on

Keep auto-tagging switched on in DV360, so the `dclid` reaches your landing page.

</li>

<li markdown="block">

### One-time sign-in

A DV360 user with access to the advertiser signs in once to authorise sending. Your Second Stage contact sends you the link.

</li>

</ol>
